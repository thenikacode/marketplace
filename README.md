# thenikacode marketplace

Open-source Claude Code plugins by [Nika Code](https://thenikacode.com).

## Install (Claude Code 2.1.275+)

```bash
claude plugin install keep-or-rebuild --marketplace thenikacode/marketplace
claude plugin install first-step --marketplace thenikacode/marketplace
```

Or inside an active Claude Code session:

```text
/plugin install keep-or-rebuild --marketplace thenikacode/marketplace
/plugin install first-step --marketplace thenikacode/marketplace
```

## Plugins

| Plugin | Version | What it does |
|---|---|---|
| [keep-or-rebuild](https://github.com/thenikacode/keep-or-rebuild) | `0.1.2` | Checks live pricing pages and licenses to tell you whether to keep paying for a SaaS tool, switch to a free/open-source option, or rebuild only the slice you use. |
| [first-step](https://github.com/thenikacode/first-step) | `0.1.0` | Interviews you one sharp question at a time before any agent touches code, turning rough ideas into a verifiable first step. Also works with `npx skills add thenikacode/first-step -g`. |
