# thenikacode marketplace

Claude Code plugins by Nika Code.

In Claude Code 2.1.275 or later:

```
/plugin install keep-or-rebuild --marketplace thenikacode/marketplace
```

<details>
<summary>Older Claude Code versions</summary>

```
/plugin marketplace add thenikacode/marketplace
/plugin install keep-or-rebuild@thenikacode
```

</details>

| Plugin | What it does |
|---|---|
| [keep-or-rebuild](https://github.com/thenikacode/keep-or-rebuild) | Tells you whether to keep paying for an app, switch to open source, or rebuild only the part you use. Quotes licenses from the LICENSE files. |
